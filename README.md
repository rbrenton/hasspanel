# hasspanel

Generate config for OpenHASP (jsonl) and Home Assistant (yaml) based on `config.php`. Currently using a [SenseCAP Indicator D1](https://www.seeedstudio.com/SenseCAP-Indicator-D1-p-5643.html?sensecap_affiliate=65YaiPp&referring_service=link) with with firmware from https://github.com/HASwitchPlate/openHASP/releases.
